# 功能拓展设计

这里存放**不改变闲聊主链职责**的功能拓展：表情包、后续类似的表达或能力扩展。

`docs/superpowers/specs/` 仍是运行时主链、治理和已落地模块的规格。功能拓展单独成夹，避免和主链规格混在一起。

## 一篇拓展怎么写

每个功能一个子目录：

```text
docs/features/<功能>/
  README.md    功能说明：给管理员和产品看，不写实现细节
  design.md    设计文档：给实现看，含边界、状态、链路、不做清单
```

功能说明只回答：做什么、不做什么、管理员会看见什么、群友会遇见什么。  
设计文档只回答：对象、规则、和现有代码怎么接、按什么顺序做。
