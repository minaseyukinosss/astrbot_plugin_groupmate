# 闲聊表情包

Groupmate 的闲聊可以像群友一样，在合适的时候给自己的回复配一张表情图。

表情不是搜图指令，也不是制作器。Bot 必须先认识每张图在说什么。闲聊里有两种发图：

- **配图**：先写出回复，再按自己这句话从图鉴里配一张，跟文字同一条消息发出。
- **要图**：群友向 Bot 要表情时，从图鉴里给。先回一句，再另发图；要很多张就用合并转发一次最多给 15 张。平常怎么说都行，不靠固定句式；检索看的是对方要哪种，不是唤醒词，也不是 Bot 的接话。

认不得的图不会发出去。发不出图时仍要回话，用当下口吻说发不了，不写死句子，也不说「图库里没有」。

## 群友会遇到什么

- 闲聊回复有时是纯文字，有时是短句再跟一张图（配图，跟文字同一条）。
- 直接跟 Bot 要表情（「来张表情」「发个无奈的」「来个可爱的」「有表情包吗」），Bot 先回一句，再另发图，仍是自己的口气，不是搜图指令。
- 要很多张（「来一堆」「多来点」）时，先回话，再用合并转发一次最多给 15 张，不会在群里连刷 15 条。合格图不够 15 张就有多少给多少。
- 发不出图（对不上、库里没有可发的、关系不够、不安全）时，仍回一句当下的话，说明给不了；这句是现写的，不是固定台词。关掉闲聊配图不影响要图发图，只是平常聊天不再自动配。
- 不是每条消息都配图；安全、文字复读、认真纠错时不配。
- 偷来的图就是 Bot 自己的图，各群闲聊都可以配。
- 大家跟同一张自定义表情时，Bot 是否跟着复读，由闲聊复读链路负责，不在本页功能里。照片和商城表情不跟。

## 管理员会遇到什么

管理页新增「表情图鉴」：

1. **待认知**：刚从群里收到、还没写清含义、或者视觉没认出来的图。GIF 写完含义后也停在这里，须管理员确认才进图鉴。
2. **图鉴**：已经能用的图。每张卡上写着 Bot 认为这张图在说什么。
3. **详情**：改含义、启用/停用、删除、重新认知。来源群只作记录，不限制发送。

也可以手传图片并手写含义。没有视觉模型时，捕获仍会进待认知，但必须手写含义才能用来发送。

## 四件事

| 能力 | 一句话 |
|---|---|
| 认知 | 每张图有一句可核对的含义。空含义不能发。 |
| 配图 | 先写回复，再从含义对得上的图里随机抽一张。 |
| 要图 | 群友向 Bot 要表情时按对方要的给；先回话再另发图，很多张走合并转发最多 15 张；给不了也要回话。 |
| 捕获 | 群友发的自定义 GIF/PNG 可以收下；同一张图再发不会重新认识。 |

## 明确没有的

- `bq 开心` 这类搜图指令（群友用平常说话向 Bot 要图，不是这类指令）
- 在线制作表情包
- 把 QQ 商城表情、系统黄豆当文件偷走
- 给图建「开心 / 难过」文件夹当主分类
- 把照片、截图、证件当表情发出去
- 表情复读（跟同一张图）：要做，但不在本功能；走现有闲聊复读链

## 开关

- **配图**和**偷取**分开。关掉偷取，已经认识的图仍可配、仍可应群友要图。
- 关掉配图只关掉闲聊伴奏，不关掉回话。群友要图时仍尝试从图鉴给；给不了就按当前人格现写一句，说明这回给不了，不套固定句子，也不沉默。
- 偷取只跟总开关：打开后，已启用 Groupmate 的群都会收；关掉则都不收。
