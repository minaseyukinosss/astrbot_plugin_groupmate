# Groupmate 当前群影子记录查看入口设计

日期：2026-07-21

## 1. 背景与目标

Groupmate 已支持零发送影子模式、聚合统计和按决策 ID 人工标注，但管理员目前无法在 AstrBot 聊天入口中查看可供标注的近期记录。`/groupmate_shadow_stats` 虽然返回最近 10 条决策的基础字段，却不按当前群隔离，也不提供足以判断回复时机的脱敏消息摘要。

本次增加一个仅限管理员使用的查看命令，使管理员能够在当前群查看近期影子决策，并直接取得现有 `/groupmate_shadow_label` 所需的完整决策 ID。

## 2. 调研结论

AstrBot 4.24+ 官方插件接口支持：

- 使用 `@filter.command(...)` 注册带类型参数的指令；
- 使用 `@filter.permission_type(filter.PermissionType.ADMIN)` 限制管理员调用；
- 使用 `yield event.plain_result(...)` 返回纯文本；
- 注册后的指令自动进入 WebUI 指令管理。

现有 `shadow_decisions` 表已经保存查询所需的 `group_hash`、决策 ID、触发类型、动作、置信度、原因、限流判断、可选脱敏上下文、标签和创建时间，因此无需数据库迁移。

## 3. 用户入口

新增命令：

```text
/groupmate_shadow_recent [数量]
```

- 无参数时返回当前群最近 5 条。
- 数量限制为 1 至 10；小于 1 时按 1 处理，大于 10 时按 10 处理。
- 非整数参数由 AstrBot 的指令参数解析机制拒绝。
- 命令仅限 AstrBot 管理员使用。
- 查询结果按创建时间和数据库自增 ID 倒序排列。

保持现有平铺命名，不在本次迁移到指令组，以免改变既有管理命令。

## 4. 当前群隔离

查询必须只返回命令所在群的记录：

1. 从事件取得当前群号；
2. 使用影子模式现有的本地 HMAC 密钥生成 `group_hash`；
3. 在 SQLite 查询中使用 `group_hash = ?` 过滤；
4. 不返回真实群号、群散列值或其他群的记录。

查看入口可在影子模式已经关闭后读取保留期内的历史记录。为此，`HmacIdentityHasher` 增加 `load_existing(key_path)` 类方法：文件存在且为合法 32 字节密钥时返回 hasher，不存在时返回 `None`，损坏时抛出原有的密钥错误。Bridge 只通过该接口按需加载旧密钥；若密钥不存在，则当前实例不可能存在可匹配的合规记录，返回空结果，不为一次只读查询创建新密钥。

## 5. 存储查询接口

在 `SQLiteMemoryStore` 增加只读方法：

```python
recent_shadow_decisions(group_hash: str, limit: int = 5) -> List[Dict[str, Any]]
```

行为：

- 在方法内部再次把数量限制到 1 至 10，不能只依赖命令层；
- 只选择渲染需要的列；
- 只解析 `context_json`，不读取其他消息表补充正文；
- JSON 为空、损坏或类型不正确时将上下文视为不可用；
- 不修改记录、不延长保留期，也不执行清理。

返回给命令层的每条记录包含：

- `decision_id`；
- `trigger`；
- `action`；
- `confidence`；
- `reason_code`；
- `would_rate_limit`；
- `label`；
- `created_at`；
- `latest_message`，来自脱敏上下文最后一条有效文本。

## 6. 输出格式与隐私

结果使用紧凑纯文本。标题说明记录数和标注方式，每条记录展示：

```text
[1] 2026-07-21 14:30:12
ID: <完整决策 ID>
判断: 回复 0.84 | 原因: useful_contribution | 标签: 未标注
消息: 成员2：这个配装是不是还差点抗性？
```

具体约束：

- 时间按 AstrBot 宿主机本地时区格式化到秒；
- 动作和标签使用固定中文映射，未知值保留安全的原始短值；
- 置信度保留两位小数；
- 若 `would_rate_limit=true`，在判断行追加“会被限流”；
- 显示完整决策 ID，确保可以直接复制到标注命令；
- 只取脱敏上下文最后一条包含非空文本的消息；
- 发送者只允许使用上下文中已有的“成员N”脱敏标签；不符合此格式时不显示发送者；
- 消息中的换行和连续空白压缩为单个空格；
- 消息摘要最长 80 个字符，超出时以 `...` 结尾，最终长度仍不超过 80；
- `context_json` 为空、损坏、无有效文本或关闭文本存储时统一显示“未保存文本”；
- 不展示 `group_hash`、`sender_hash`、完整上下文、模型 ID、延迟、内部错误详情或特征 JSON。

空结果返回：

```text
当前群暂无影子决策记录。
```

列表结尾附带：

```text
标注：/groupmate_shadow_label <决策ID> <必须回复|可以回复|必须沉默|跳过>
```

## 7. 组件边界

- `groupmate/memory.py`：负责当前群过滤、排序、限量和安全解析脱敏上下文。
- `groupmate/evaluation/shadow.py`：提供已有 HMAC 密钥的只读加载接口。
- `groupmate/astrbot_adapter.py`：负责把当前群号转换为已有 `group_hash`，并把查询暴露给插件入口。
- `groupmate/shadow_admin.py`：不依赖 AstrBot，负责动作/标签中文映射、时间、摘要截断和完整列表渲染。
- `main.py`：只负责管理员命令、参数接收、调用 Bridge 和发送纯文本结果。
- `tests/test_shadow_storage.py`：验证群隔离、排序、限量、上下文解析和隐私字段。
- `tests/test_shadow_admin.py`：验证默认与边界数量、空结果和完整渲染格式。
- `tests/test_shadow_bridge.py`：验证当前群号经相同 HMAC 密钥映射后只能得到本群记录。
- `main.py` 的命令包装沿用现有 AstrBot 装饰器模式，不为加载框架装饰器编写脆弱的模拟测试；核心行为全部由上述模块测试覆盖，并在 AstrBot 测试群手工验证命令解析和管理员权限。

## 8. 错误处理

- 当前事件没有群号时返回“只能在群聊中查看影子决策记录。”
- HMAC 密钥不存在时返回空结果，不创建新密钥。
- SQLite 查询失败时记录 AstrBot 服务端错误日志，并向群内返回“影子决策记录暂时无法读取。”，不泄露路径或异常详情。
- 单条上下文损坏不得导致整页查询失败。

## 9. 测试与验收

自动化测试必须覆盖：

1. 两个群的记录只返回当前群。
2. 默认返回 5 条并按时间倒序。
3. 数量在存储层和命令层均限制为 1 至 10。
4. 显示完整决策 ID、中文动作、置信度、原因和标签。
5. 已保存上下文只显示最后一条有效脱敏消息。
6. 摘要压缩空白且不超过 80 个字符。
7. 未存正文和损坏 JSON 不泄露内容，非法发送者值不会进入输出。
8. `would_rate_limit` 正确显示。
9. 空结果和非群聊调用返回明确提示。
10. 现有统计、标注、导出和零发送行为不回归。
11. 完整测试套件通过。

AstrBot 测试群手工验收：

```text
/groupmate_shadow_recent
/groupmate_shadow_recent 1
/groupmate_shadow_recent 10
/groupmate_shadow_recent 50
```

确认结果只包含当前群记录，完整 ID 可直接用于现有标注命令，普通成员无法调用，并且 WebUI 指令管理中能看到新命令。

## 10. 非目标

本次不实现：

- 跨群查看或全局管理面板；
- 完整上下文详情命令；
- 翻页游标、日期筛选或标签筛选；
- 在群内导出影子数据；
- 修改影子表结构或保留策略；
- 自动切换正式模式或自动标注。
